1. As a cacao farmer, I want to capture and process digital images of dried cacao beans through an automated system, so that I can bypass slow manual sorting processes and save time and labor.
   - **Acceptance Criterion 1:** The system successfully accepts image uploads or live camera capture in standard formats (JPEG, PNG).
   - **Acceptance Criterion 2:** The automated image processing completes analysis within 5 seconds per batch.

2. As a local processor, I want the system to classify cacao beans into seven distinct categories (good, moldy, cracked, insect-infected, flat, germinated, and clustered), so that I can accurately identify defects and maintain strict export quality control standards.
   - **Acceptance Criterion 1:** The machine learning model correctly identifies and categorizes beans into all seven specified defect categories.
   - **Acceptance Criterion 2:** The interface generates a summary breakdown report displaying the total count and percentage of each category per batch.

3. As an agricultural quality inspector, I want the application to display real-time bounding boxes and class labels on a live video feed, so that I can instantly evaluate and verify bean batches without relying on subjective human judgment.
   - **Acceptance Criterion 1:** Bounding boxes and distinct class labels dynamically overlay on individual beans during live video playback.
   - **Acceptance Criterion 2:** The live feed maintains a smooth display performance with clear label readability during inspection.
